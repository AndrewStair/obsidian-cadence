# Cadence Product Explainer Plan

**Format:** animated product explainer with real UI screen-recording inserts  
**Audience:** people who want a local-first project and planning system inside Obsidian  
**Target duration:** 60 to 75 seconds  
**Tone:** calm, capable, optimistic, and practical  
**Style:** dark editorial motion graphics with restrained purple, cyan, green, and coral accents

This is not a tutorial recording. It is a short product explainer: it shows the problem, demonstrates Cadence's planning loop, and leaves the viewer with a clear sense of what the product is for.

## Core Message

Cadence brings the pieces of project work already living in an Obsidian vault into one clear loop: capture it, give it context, choose what comes next, and make time for it.

## Screen Recording Shot List

Record each shot in the public test vault with only generic demonstration data. Capture at 1920x1080, with Cadence in dark mode and the default bundled background. Keep the cursor movement deliberate and slow.

1. **Quick Capture:** trigger `Ctrl+D`, enter `Plan client kickoff`, set a date, and save. Record 5 seconds.
2. **Inbox decision:** open the captured item in Inbox, link it to a demo project, and show it leaving the unprocessed list. Record 6 seconds.
3. **Project creation:** create `Website refresh`, enter a one-sentence brief and desired outcome, then add milestone `Content structure approved`. Record 8 seconds.
4. **Portfolio organization:** move `Website refresh` into a generic `Marketing` or `Product` portfolio in Organize mode. Record 6 seconds.
5. **Node Map connection:** drag from a project edge handle to another project, select `Tentative Next`, then click the arrow to show its relationship control. Record 9 seconds.
6. **Node Map layout:** select two cards, align them, and show snap-to-grid while moving a group. Record 6 seconds.
7. **Calendar scheduling:** create a `Website refresh focus block`, drag it to a morning slot, then switch Day to Week. Record 8 seconds.
8. **Calendar overlap:** show two overlapping demo meetings sharing space, then an isolated focus block using full width. Record 5 seconds.
9. **Home overview:** show a calm final Home dashboard with current work, without personal notes, names, or dates. Record 5 seconds.

## Demo Data

Use names that are short, generic, and visually readable:

- Portfolio: `Product`, `Marketing`, `Operations`
- Projects: `Website refresh`, `Client kickoff`, `Reporting cleanup`, `Team handbook`
- Milestones: `Content structure approved`, `First review complete`, `Launch checklist ready`
- Calendar events: `Focus block`, `Project review`, `Team sync`

Do not use personal names, customer data, internal company terminology, vault paths, or real calendar commitments.

## Motion and Design Rules

- Use Cadence's current dark UI as the source of truth. Do not recreate an unrelated generic dashboard.
- Let interface states drive the motion: cards assemble, arrows draw, and scheduled blocks snap into time.
- Use no more than four accent colors in a scene: purple for Cadence, cyan for capture, green for enablement, coral for hard dependencies.
- Prefer 200-400 ms motion with ease-out timing. Avoid excessive bouncing, spinning, or particle effects.
- Keep on-screen text to one short sentence per beat. The UI supplies the supporting detail.
- Use licensed or original music with a light, precise electronic feel. No voice-over is necessary for the first cut; captions can carry the story.

## Delivery Package

1. A 16:9 master video at 1920x1080, H.264 MP4.
2. A captioned version with burned-in text.
3. A silent looping 15-second cut for a project landing page or README.
4. The individual screen recordings, named by storyboard shot number.
5. A folder of exported SVG/PNG motion assets, including the workflow and relationship diagrams used in the user guide.

## Capture Checklist

- Reset Cadence to the default bundled background.
- Use the public plugin build and the public test vault only.
- Set browser/Obsidian zoom to 100% and hide unrelated panes.
- Disable desktop notifications and close other applications.
- Record a few seconds of stillness before and after every interaction.
- Review recordings at normal speed to verify readable cursor movement and no private data.
